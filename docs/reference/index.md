# API reference

The API reference is generated from Eurybia's Python docstrings at build time.

- [`SmartDrift`](smartdrift.md): configure, compile, and report a drift analysis.
- [`SmartPlotter`](smartplotter.md): generate individual drift visualizations.
- [Report generation](report-generation.md): build the HTML report.
- [Data loader](data-loader.md): load the example datasets.
