# Tutorials

The tutorial notebooks provide a progressive introduction to Eurybia. Clone the repository and open them with JupyterLab, or view them directly on GitHub.

```bash
python -m pip install jupyterlab
jupyter lab tutorial/tutorial01-Eurybia-overview.ipynb
```
